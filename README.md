# اكشف حقيقتك

تجربة عربية (RTL) للتأمل الشخصي حول مفهوم فضاء كوني. اختبار واحد فقط بعنوان «اكتشاف الذات». React + TypeScript + Vite، بلا خادم ولا قاعدة بيانات ولا خدمات مدفوعة ولا مفاتيح API.

## التشغيل المحلي
```
npm install
npm run dev
```

## الصفحات والمسارات (hash)
- `#/` الصفحة الرئيسية وفيها يبدأ الاختبار مباشرة.
- `#/result/:id` صفحة النتيجة.
- `#/about` · `#/privacy` · `#/disclaimer` صفحات المعلومات.

## الفكرة
- اختبار واحد: 12 سؤالًا، 4 خيارات لكل سؤال، بلا عشوائية.
- يقيس ستة أبعاد: الدافع الداخلي، الثقة بالنفس، التعامل مع المشاعر، العلاقات، أسلوب القرار، والنظرة للمستقبل.
- ست نتائج (بروفايلات): المستكشف، المرساة، الشرارة، الحارس، التائه المتأمل، الجسر. لكل بروفايل: اسم، وصف، تحليل، نقاط قوة، جوانب للتأمل، ونصيحة عملية.
- احتساب النتيجة في `src/engine/score.ts` بالأوزان مع كسر التعادل (أعلى وزن مفرد ثم ترتيب النتائج).


## الرؤية البصرية
خلفية ليلية عميقة (#050816) مع تدرجات بنفسجية وكهربائية وفيروزية ولمسة غروب برتقالية، وحقل نجوم خفيف، وبطاقات زجاجية شفافة، وخط IBM Plex Sans Arabic. لا أحمر ولا أسود فحمي.

## الخط (IBM Plex Sans Arabic)
- الخط مُستضاف محليًا في `public/fonts/` بصيغة woff2 من أوزان 400 و500 و600 و700، ولا يُحمَّل من Google Fonts.
- التعريفات في `src/styles/fonts.css` مع `unicode-range` لنطاقات arabic وlatin وlatin-ext، و`font-display: swap`.
- يُستورد `fonts.css` قبل `global.css` في `src/main.tsx`، ويُستخدم عبر المتغير `--font` في كل الصفحات والمكوّنات.
- الترتيب البديل عند تعذر التحميل: `"Noto Sans Arabic", "Segoe UI", Tahoma, system-ui, -apple-system, sans-serif`.
- الترخيص: SIL Open Font License 1.1 (انظر `public/fonts/OFL.txt`). الحجم الكلي للملفات ‎~300KB.
- يعمل الموقع دون اتصال: لا طلبات لأي خط خارجي، والخطوط تُخدم من الأصل نفسه.

## حالة التنفيذ
- مُنفَّذ ومُختبَر: البدء داخل الصفحة الرئيسية بانتقال ناعم، سؤال لكل خطوة، شريط تقدم، رجوع وتغيير الإجابة، محرك النتائج، صفحة النتيجة، مشاركة واتساب وX، نسخ الرابط والنص، إعادة الاختبار، صفحات المعلومات.
- تنزيل بطاقة النتيجة كصورة PNG مرسومة على canvas بلا مكتبات مدفوعة.
- الخط مُدمج محليًا بأوزانه الأربعة وتأكد تحميله وتطبيقه وعمله بلا اتصال.
- تم التحقق من `npm run build` ومن مسار الاختبار الكامل عبر متصفح آلي.
